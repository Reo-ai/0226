## 完全パッケージ

## 基本設定

| 項目 | 内容 |
|------|------|
| BPM | 140 |
| Key | Cメジャー |
| 拍子 | 4/4 |
| コード進行 | C → Am → F → G（各1小節） |

---

## Before MIDI

**特徴：C4〜E4（長3度・3音のみ）全て4分音符**

| 小節 | コード | メロディ |
|------|--------|----------|
| 1 | C | C4♩ E4♩ D4♩ C4♩ |
| 2 | Am | E4♩ D4♩ C4♩ D4♩ |
| 3 | F | D4♩ E4♩ D4♩ C4♩ |
| 4 | G | E4♩ D4♩ C4♩ 休♩ |

```
音域イメージ：
E4 ──●──────●──────●──●──●──●──
D4 ────────●──●──────●──●──●───
C4 ──────●──────────●──────────●
         ↑狭い！C〜Eの3音しか使っていない
```

---

## After MIDI

**特徴：C4〜A4（長6度・歌いやすい適切な音域）8分音符混在**

| 小節 | コード | メロディ |
|------|--------|----------|
| 1 | C | C4♪ E4♪ G4♩ **A4♩** G4♩ |
| 2 | Am | A4♩ G4♪ E4♪ F4♩ E4♩ |
| 3 | F | F4♪ G4♪ **A4♩** G4♩ F4♩ ← ピーク |
| 4 | G | G4♩ F4♪ E4♪ D4♩ C4♩ |

```
音域イメージ：
A4 ────────────●──────●──●──────
G4 ──────────●──────●──────●────
F4 ──────────────────────●──────
E4 ────────●──────●──────────●──
D4 ──────────────────────────●──
C4 ──●──────────────────────────
         ↑C〜A（長6度）歌える！
```

---

## 改善ポイント

```
❌ Before                      ✅ After
──────────────────────────────────────────
音域3音（C4〜E4）   →   音域6音（C4〜A4）
長3度（狭い）       →   長6度（歌いやすい）
全て4分音符         →   8分音符混在
方向感なし          →   山型（3小節目ピーク）
```
