# Affiliate Pilot AI

AIアフィリエイト攻略司令塔。完全初心者（90日で月5万円を目指す）から、すでに集客できているアカウント（初月5万円チャレンジ）まで、「今日なにをすればいいか」を示し、案件選び・コンテンツ作成・学習・成果分析をひとつのアプリで進めます。

- 月額0円で動きます（有料AIは任意。AIなしでもルールとテンプレートで主な機能が使えます）
- PCで動かす単一ユーザー向けWebアプリです。スマホからは同じWi-Fi内でアクセスできます
- 収益の達成を保証するものではありません。発生報酬・確定報酬・入金額は分けて扱います

## 機能

| 画面 | パス | 内容 |
|---|---|---|
| ダッシュボード | `/` | 今日やること（作業可能時間内）、目標と実績、ロードマップ、次のアクション、学習進捗 |
| 初期設定 | `/onboarding` | 経験・目標月収・期限・作業時間・媒体・ジャンル・既存アカウント・予算 |
| AI司令塔 | `/coach` | タスクの優先順位付け、AIによる計画の組み直し、手動タスク、AIコーチへの質問、週次振り返り |
| 90日ロードマップ | `/roadmap` | 4フェーズ×マイルストーン（データから自動判定＋手動チェック） |
| 初月5万円チャレンジ | `/challenge` | 現状診断、逆算シミュレーター、30日プラン、必要数（計算）と実績の比較、改善提案 |
| アカウント | `/accounts` | ブログ・SNSの直近30日の数字（空欄は未計測） |
| 戦闘力診断 | `/accounts/assessment` | 集客力・反応・導線・案件適合・成約実績・データ信頼度、優先改善3つ、評価基準の編集 |
| 攻略大学 | `/academy` | 全8講座・57レッスン（本文・用語解説・チェックリスト・クイズ・実践課題・AIに質問・出典と確認状態） |
| 案件分析 | `/offers` | 案件の登録・絞り込み・CSV取込・適合性評価・計測リンク（`/go/コード?ch=媒体`） |
| 案件比較 | `/offers/compare` | 同じ仮定での収益シミュレーション、おすすめ理由・懸念点・確認項目 |
| コンテンツ工房 | `/content` | 10種類の原稿生成、公開前チェック（PR表記・注意表現・ファクトチェック）、コピー、Markdown出力、公開URL記録、動画化 |
| 自動化センター | `/automation` | 日次タスク・下書き・成果集計・改善案・週次レポートのジョブ（draft / awaiting_review / approved / completed / failed）、定型文、投稿チェックリスト |
| 収益分析 | `/analytics` | 日別・週別・月別・媒体別・案件別、CTR・CVR・承認率・達成率・1時間あたり確定報酬、CSV入出力 |
| 設定 | `/settings` | AI接続（モデル選択・接続テスト・導入手順）、バックアップ／復元、デモデータ |

## はじめかた

必要なもの：Node.js 20 以上（22 推奨）

```bash
cd affiliate-pilot
cp .env.example .env
npm install          # Prisma Client も生成されます
npm run setup        # データベース作成＋教材・ASP情報の投入
npm run build
npm start            # http://localhost:3000
```

開発中は `npm run dev` でも動きます。

### ローカルAI（任意・無料）

1. [Ollama](https://ollama.com/download) をインストール
2. `ollama pull qwen2.5:7b`（数GB。PCの目安はメモリ16GB以上）
3. Ollama を起動したまま、アプリの「設定 → 接続テスト」を押す

| モデル | PCの目安 |
|---|---|
| `qwen2.5:3b` | メモリ8GB以上（軽量） |
| `qwen2.5:7b` | メモリ16GB以上（おすすめ） |
| `gemma3:12b` | メモリ24GB以上、またはVRAM 12GB以上 |
| `qwen2.5:14b` | メモリ32GB以上、またはVRAM 16GB以上 |

AIの選び方は「自動（Ollama → Claude → AIなし）」が既定です。Claude は `.env` に `ANTHROPIC_API_KEY` を入れたときだけ使います（従量課金）。どれも使えないときは、ルール・テンプレート・手動入力で作業を続けられます。AIの出力はすべて Zod で検証し、形式が違えばルールの結果に切り替えます。

### スマホから使う

PCとスマホを同じWi-Fiにつなぎ、スマホで `http://PCのIPアドレス:3000` を開きます。計測リンクにPCのアドレスを使いたいときは `.env` の `APP_BASE_URL` を設定してください。

### インターネットに公開する場合

初期版は単一ユーザー・LAN内での利用を前提にしています。公開する場合は最低限、次の対策が必要です。

- ログイン：`.env` の `APP_PASSWORD` を設定するとパスワードが必要になります（計測リンク `/go` とトークン認証の `/api/pipeline` は対象外）
- HTTPS
- 永続的なデータ保存とバックアップ（SQLite ファイルが消えない環境）
- 無料のクラウドホスティングではローカルAIは常時動きません（AIなし、または Claude で運用）

## データ

- SQLite（`prisma/dev.db`）。Git にはコミットしません
- 金額は円の整数、CTR・CVR・承認率は 0〜1 の比率で保存
- 未計測は NULL（0 と区別）。分母が 0 または未計測の率は計算しません
- 成果記録は「日付・媒体・アカウント・案件・公開」の組み合わせで1件にまとめ、二重集計を防ぎます
- デモデータは `isDemo` で区別し、設定画面からまとめて削除できます
- バックアップ：設定画面の「バックアップをダウンロード」（JSON）。`prisma/dev.db` をコピーしても保存できます
- 教材（`lib/academy/courses/*.ts`）は起動時に DB と同期します。規約などの出典は「未確認／確認済み／古い可能性」と最終確認日を保存します

主なコマンド：

```bash
npm run db:migrate   # スキーマ変更時（開発）
npm run db:seed      # 教材・ASP情報の再投入（何度実行しても同じ）
npm run db:reset     # データベースを作り直す（全データ削除）
```

## 動画パイプライン連携

リポジトリ直下の TikTok/Instagram パイプラインと連携できます。コンテンツ工房で「動画にする」を押すと待ち行列に入り、PCの `npm start -- hub-sync --loop 5` が取りに来て画像→動画を生成し、結果を返します。

- このアプリ：`.env` に `PIPELINE_TOKEN`
- リポジトリ直下：`.env` に `HUB_URL=http://localhost:3000` と `HUB_TOKEN`（同じ値）

## 設計メモ

- AI：`lib/ai` の `AIProvider`（`generateText` / `generateStructuredOutput` / `healthCheck`）を `OllamaProvider`・`ClaudeProvider`・`FallbackProvider` が実装。役割（戦略・案件分析・コンテンツ・分析・学習）はプロンプトで切り替え、共通ルール（実績の捏造禁止・最新条件を推測しない・架空レビュー禁止・実績と仮説の区別）を必ず付けます。ユーザー入力や外部データは `<data>` で囲み、命令として扱いません。Ollama の接続先はローカル／LANのみ許可
- 投稿：`lib/publishing/adapters.ts`。初期版は手動投稿（コピー → 投稿 → URL記録）のみ。公式API対応時はアダプターを追加します。スパム投稿・無断スクレイピング・規約回避は実装しません
- SaaS化：単一ユーザーのプロフィールを `lib/profile.ts` で取得しています。認証を入れるときは、ここをセッションのユーザーに置き換え、各モデルにユーザーIDを持たせます
- UI：Tailwind CSS v4 と shadcn/ui 方式の部品（`components/ui`、Radix UI ベース）。この環境では shadcn の配布サイトに接続できなかったため、同じ構成で手書きしています
