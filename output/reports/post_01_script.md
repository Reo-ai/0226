---

成功者と普通の人の朝、何が違うか知ってる？

まず一つ目。成功者は起きた瞬間にスマホを見ない。
代わりに、たった5分間だけ「今日何をするか」を頭の中で整理する。
これだけで午前中の集中力が全然変わる。

二つ目。必ず体を動かす。ジムじゃなくていい。10分で十分。
朝に体を動かすと、脳の覚醒スイッチが入って判断力が上がる。

三つ目。起きてすぐ水を500ml飲む。
寝ている間に失った水分を補うだけで、頭のもやがスッと消える。

この3つ、めちゃくちゃ地味でしょ？
でも習慣って、積み重なると1年後の自分が全然違う人間になってる。
成功の哲学って、結局これなんです。

明日の朝から一個だけ試してみて。
保存して毎朝見返してね。

## シーン構成・映像指示（CapCut／Vrew編集用）

### Scene 1｜0〜3秒：フック（最重要）

```
映像イメージ:
  ① 暗い部屋でアラームが鳴る手元 → 0.5秒
  ② 即カット：明るい朝、窓から光が差し込む → 0.5秒
  ③ 顔をしっかり映す（またはテキストのみ）→ 2秒

テロップ（画面中央・大きく・即表示）:
  「成功者と普通の人の朝の違い」
  （フォント：太ゴシック、白、テーマカラー（金）で縁取り）

BGM: この瞬間は無音 or 一瞬の緊張SE → 次のシーンからBGM開始
```

### Scene 2｜3〜10秒：違い①（スマホ封印）

```
映像イメージ:
  ① スマホをベッドの横に伏せて置く手
  ② 目を閉じて深呼吸している人（横顔）
  ③ 手帳にペンを走らせるシーン

テロップ（画面下部 or 中央）:
  「❌ 起きてすぐスマホ」（赤でバツ）
  「✅ 5分間マインドセット」（テーマカラーでチェック）
  「→ 午前中の集中力が別物に」

カット間隔: 2〜3秒ごとに切り替え
```

### Scene 3｜10〜17秒：違い②③（運動・水）

```
映像イメージ:
  ① 朝の軽いストレッチ・腕立て（10秒でいいと伝わる演出）
  ② コップに水を注いで一気に飲む

テロップ:
  「✅ 朝10分 体を動かす」
  「✅ 起床後すぐ 水500ml」
  「→ 脳のスイッチON」

BGM: テンポを少し上げる（情報を畳みかけるリズム）
```

### Scene 4｜17〜25秒：哲学パート（感情に刺さる）

```
映像イメージ:
  ① 充実した表情でコーヒーを飲む朝の人
  ② カレンダーが積み重なる演出（1日→1週間→1年）
  ③ 少し引いて、清々しい朝の空間を映す

テロップ:
  「習慣が積み重なると」
  「1年後の自分が全然違う」
  「成功の哲学って結局これ」

BGM: 感情が乗るアップリフティング系に切り替え
```

### Scene 5｜25〜30秒：CTA

```
映像イメージ:
  ① 画面を見ている人 or テキストのみ

テロップ（大きく・動きをつけて）:
  「明日の朝から1個だけ試して」
  「🔖 保存して毎朝見返してね」
  「👆 フォローで毎日こういう情報流します」
```
