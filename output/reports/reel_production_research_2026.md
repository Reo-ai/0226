## 1. 動画の黄金構成（2026年版）

### 基本フォーマット（30秒の場合）

```
[ 0〜3秒  ] ── フック（最重要）視聴者の60%がここで離脱か継続かを決める
[ 3〜20秒 ] ── 本題（価値提供）テンポよく・カット多め
[ 20〜27秒] ── まとめ＋商品自然紹介
[ 27〜30秒] ── CTA（保存・シェア・プロフリンクへ）
```

### 尺別の使い分け

| 尺 | 用途 | 平均視聴完了率 |
|---|---|---|
| **15秒** | フック系・驚き系・ネタ系 | **76%**（最高） |
| **30秒** | ハウツー・リスト系 | 55〜65% |
| **45〜60秒** | ストーリー・体験談系 | 45〜55% |
| **90秒〜** | 深掘り解説・インタビュー系 | 30〜45% |

→ **最初は15〜30秒に絞るのが正解**。短いほどアルゴリズムに好まれる。

## 2. フック（冒頭3秒）完全攻略

### 絶対NG：スロービルドアップ
```
❌「こんにちは！今日は○○について話します〜」
❌「最近筋トレ始めてみたんですけど〜」
```
→ 最初の0.5秒で視聴者は「これは自分に関係ある？」を判断する。前置き厳禁。

### バズるフック9パターン（自己啓発向け）

| パターン | テンプレート | 例 |
|---|---|---|
| **数字の衝撃** | ○○するだけで△△が変わる | 「朝5分でIQが7上がる方法」 |
| **タブー暴露** | 99%の人がやっている○○の間違い | 「筋トレしてるのに痩せない本当の理由」 |
| **限定感** | ○○を知っている人だけが得をする | 「月収100万の人だけが知っている習慣」 |
| **共感＋転換** | 昔の私もそうだった。でも○○で変わった | 「ずっと睡眠不足だった私が変えた1つのこと」 |
| **問いかけ** | ○○できてる？実はほとんどの人が… | 「正しく寝れてる人、実は3割しかいない」 |
| **警告系** | やめてください、○○は危険です | 「これ食べてたら筋肉が落ちます」 |
| **逆説** | ○○すればするほど△△になる | 「頑張れば頑張るほど成果が出ない理由」 |
| **速攻価値** | ○秒で教えます | 「15秒で分かる睡眠の質を上げる方法」 |
| **Before/After** | ○ヶ月前の私 → 今の私 | （映像で見せる） |

### 視覚的フックも必須
- 最初の **2秒以内に2カット** 入れる（動きで目を引く）
- **テキストオーバーレイ** を0〜1秒で表示（音オフで見ている人対策）
- **ズームイン・ズームアウト・パン** で動きを出す

## 3. 2026年アルゴリズムが見ている指標（重要度順）

```
1位 ── DMシェア数        ← いいねの5倍の重み付け！
2位 ── 視聴完了率        ← 30%最低ライン、45%以上で拡散開始
3位 ── 保存率            ← 1.5%以上を目標
4位 ── コメント数        ← いいねの2倍の評価
5位 ── いいね数          ← 重要だが上記より低い
```

### 各指標を上げる具体的な方法

**DM シェアを増やす（最重要）**
- 「友達に送りたくなる」内容を意識する
- 「これ○○に悩んでる友達に送って」とCTAに入れる
- 共感性・衝撃性・実用性のどれかが高い動画はシェアされやすい

**視聴完了率を上げる**
- 動画の途中で「続きが気になる」展開を入れる
- 「最後に衝撃の事実があります」と冒頭で予告する
- ループするように最後と最初をつなげる（無限再生効果）
- コメント欄を盛り上げる → コメント読みながら動画が裏でループ再生される

**保存率を上げる**
- 情報を詰め込みすぎて「保存しないと覚えられない」状態にする
- チェックリスト形式・ランキング形式は保存されやすい
- 「保存して後で実践してみて」とCTAで明示する

**コメントを増やす**
- 「AとBどっち？」などの二択質問 → 命令形CTAより47%多くコメント獲得
- 「あなたは何番から始めますか？」→ 参加しやすい質問
- 議論を誘う内容（賛否が分かれる発言）

## 4. 編集・見た目のルール

### カット・テンポ
- **2〜4秒ごとにカット**を入れる（飽きさせない）
- 無音・間・前置きをすべてカット
- テロップ（字幕）は **画面の30〜40%** を占めるサイズで、太字・視認性高め
- **音オフでも内容がわかる**字幕設計（Vrewの自動字幕が便利）

### BGM
- **トレンド曲を使う** → いいね率37%アップ（アルゴリズムが後押し）
- CapCutのトレンド音楽タブから選ぶのが最速
- ナレーション主体の動画はBGMを小さめに（声が聞こえる音量）

### テロップのデザイン（自己啓発向け）
```
フォント  : 太字ゴシック（Noto Sans Bold等）
サイズ    : 画面の1/5〜1/4程度
位置      : 中央か上部（下部は隠れやすい）
色        : 白 + 影 or テーマカラーで強調
アニメ    : ポップイン・スライドインが効果的
```

## 5. 自己啓発ジャンル別 最強フォーマット

### 💪 筋トレ
```
0〜3s  : 「これやってたら一生痩せません」（テキスト＋体の映像）
3〜15s : NG行動を3つ紹介（各5秒、カット切り替え速め）
15〜25s: 正解の方法を紹介
25〜28s: 「使っているプロテインはプロフリンクから」
28〜30s: 「保存して今日から変えよう」
```

### 😴 睡眠
```
0〜3s  : 「6時間寝てるのに疲れが取れない人へ」
3〜20s : 睡眠の質が低い原因3つを解説
20〜27s: 解決策＋「このサプリ飲み始めてから変わった」
27〜30s: 「詳しくはプロフから」
```

### 💰 お金
```
0〜3s  : 「月5万の副収入を作った話」（数字で引く）
3〜20s : 具体的な手順をステップ形式で
20〜27s: 「詳しいロードマップはこの教材にまとめた」
27〜30s: 「プロフリンクから無料サンプルあり」
```

### 💊 サプリ
```
0〜3s  : 「これ知らずにサプリ飲んでるの？」（警告系）
3〜20s : 効果的な飲み方 or 選び方を解説
20〜27s: 「私が実際に使っているのはこれ」（自然紹介）
27〜30s: 「プロフリンクから購入できます」
```

### 📚 スキル教材
```
0〜3s  : 「この3つのスキルで年収が変わった」
3〜20s : スキル紹介（一番の秘訣を最後に持ってくる）
20〜27s: 「この講座で学んだのが一番効いた」（誘導）
27〜30s: 「プロフから無料体験できます」
```

## 6. 投稿後の行動（初速が命）

投稿直後の30分〜1時間が最重要。この時間に反応が集まるとアルゴリズムが拡散を始める。

```
投稿直後  : ストーリーズでリールをシェア（インサイト「ここから見た」を増やす）
3分以内   : コメントが来たら即レス
30分以内  : 自分でコメント欄に「一番実践しやすいのどれ？」と書き込む
翌日      : インサイトを確認（3秒視聴率・保存率・シェア率）
```

## 7. このシステムとの連携フロー（完全版）

```bash
# Step 1: コンセプトとフックを生成
npm start -- generate-concept fitness --type hook --product "プロテイン"

# Step 2: Vrew用台本＋SRT字幕を生成
npm start -- generate-vrew-script fitness --duration 30 --voice energetic

# Step 3: AI画像を生成（背景素材）
npm start -- generate-reel fitness --skip-video --image-model gemini

# Step 4: Vrewで音声＋字幕を付ける（手動）
#   → output/reports/vrew_script_xxx.txt を貼り付け → AI音声生成

# Step 5: CapCutでBGM・エフェクト・テンプレート追加（手動）

# Step 6: Instagramキャプションを生成
npm start -- generate-caption fitness --product "プロテイン" --tone hook
```

## 8. バズ動画チェックリスト（投稿前確認）

- [ ] 最初の3秒にフックテキストが表示されているか
- [ ] 冒頭2秒以内に2カット以上あるか
- [ ] 音オフで見ても内容がわかる字幕があるか
- [ ] 2〜4秒ごとにカットが切り替わっているか
- [ ] トレンド曲またはトレンドサウンドを使っているか
- [ ] 視聴者が「保存したくなる」情報が含まれているか
- [ ] 二択・質問形式のCTAが含まれているか
- [ ] アフィリエイト紹介が自然に組み込まれているか（押し売り感なし）
- [ ] 最後に明確なCTA（プロフリンク誘導）があるか
- [ ] 30〜45秒以内に収まっているか
