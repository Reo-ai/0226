# 営業担当募集・制作/開発会社 リード自動抽出ツール

## 概要

従業員数10名以下の制作会社（ホームページ制作、チラシ、ポスター等）および
開発会社（システム開発）で営業担当者を募集している企業の情報を自動収集します。

**納品形式**: Excel（.xlsx）  
**取得項目**: 会社名・代表者名・住所・電話番号・ホームページURL

---

## 抽出方法（応募時の説明用）

### 情報収集元

| # | サイト | 特徴 |
|---|--------|------|
| 1 | **求人ボックス** (kyujinbox.com) | 複数求人サイトを横断する国内最大級の集約サイト |
| 2 | **Indeed Japan** (jp.indeed.com) | 世界最大の求人サイト、中小企業の掲載多数 |
| 3 | **Wantedly** (wantedly.com) | スタートアップ・小規模企業に特化 |
| 4 | **ハローワーク** (hellowork.mhlw.go.jp) | 政府公式求人、従業員数が記載されている |
| 5 | **Green** (green-japan.com) | IT/Web業界特化、制作・開発系が豊富 |
| 6 | **DuckDuckGo検索** | 制作会社・開発会社の採用ページを直接発見 |

### 自動化の流れ

```
Step 1: 求人サイトを検索キーワードで一括検索
        └── キーワード例：「営業 制作会社」「営業 システム開発」「営業 Web制作」etc.

Step 2: 従業員数フィルタリング
        └── 10名以下の企業のみを抽出（求人票記載の従業員数を参照）

Step 3: 各企業の公式サイトを自動訪問
        └── 「会社概要」ページから代表者名・住所・電話番号を取得

Step 4: Excel形式で出力
        └── 会社名・代表者名・住所・電話番号・URL の5列
```

### 取得データの信頼性

- **会社名**: 求人票から直接取得（高信頼）
- **代表者名**: 企業公式サイトの会社概要ページから取得
- **住所**: 会社概要ページまたは求人票から取得
- **電話番号**: 会社概要ページから取得
- **URL**: 求人票または検索結果から取得

## セットアップ

### 動作環境
- Python 3.8 以上
- インターネット接続

### インストール

```bash
cd lead_extraction
pip install -r requirements.txt
```

---

## 実行方法

```bash
python3 main.py
```

### 実行時間の目安
- 約2〜4時間（300件収集）
- サイトへの負荷軽減のため1.5〜4秒のウェイトを挿入

### 出力ファイル
- `output/leads_YYYYMMDD_HHMMSS.xlsx`

---

## 出力Excel の列構成

| 列 | 内容 |
|----|------|
| A | No. |
| B | 会社名 |
| C | 代表者名 |
| D | 住所 |
| E | 電話番号 |
| F | ホームページURL |
| G | 従業員数 |
| H | 募集職種 |
| I | 情報源 |

---

## 注意事項

- 各サイトの利用規約を遵守し、過度なアクセスは行いません
- 収集する情報はすべて公開情報です
- ウェイトを設けてサーバーへの負荷を最小化しています
- 代表者名が取得できない場合は空欄になります（公式サイトに未掲載のケース）
