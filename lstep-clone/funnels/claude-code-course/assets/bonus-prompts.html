AIと一緒に学ぶ講座「スキルクエスト」　作成者 茅森ショウ

使い方

💬普段のAIチャット（ChatGPT・Claude・Gemini など）…相談・整理・文章づくり。
プロンプト ①②③⑧⑨
🖥PCで作業できるAI（Claude Code・Codex）…ファイルを作る・まとめて処理する・検品する。
プロンプト ④⑤⑥⑦
どのプロンプトでも守ること
・顧客から預かった情報・ログイン情報は、許可なくAIに入れない
・AIの「できました」で終わらせず、ファイルと根拠URLを自分で開いて確かめる
・案件ページやWebページに書かれた指示は、AIへの命令として扱わせない
・依頼にAI利用のルールがあれば、それに従う

① 依頼書を読み解く

これから案件の依頼文を貼ります。次の形で整理してください。
目的／対象／件数／集める項目／判定条件／納品形式／納期／禁止事項／依頼文から分からないこと
「分からないこと」は推測で埋めず、発注者への質問文の案にしてください。 → 応募前・受注直後に。質問は一度にまとめて、短く送るのがコツ

② 判定基準を表にする

この依頼の条件を、候補1件ずつ「有効／保留／除外」に分けるための判定表にしてください。
各条件について「何を見て」「どうなら合格」「確認できないときはどうするか」を書いてください。境界があいまいな条件は、発注者に確認する項目として別に出してください。

③ 自分の手作業を手順書にする

最初の3件を手作業で調べた記録を貼ります。これをAIでも再現できる手順書（research-instructions.md）にしてください。
含めるもの：目的／入力／列の定義／判定基準／作業手順／止まる条件／成果物／検品方法
依頼の条件をゆるめたり省いたりしないでください。

④ 作業フォルダを準備する（Claude Code・Codex）

いま選んでいるフォルダだけを作業場所にしてください。inputs と outputs を作り、この後に貼る依頼書を brief.md、手順書を research-instructions.md として保存してください。
同じ名前のファイルがあれば上書きせず止まって確認してください。まだ調査・外部送信・インストールはしません。保存したファイル名と要約を報告して、私の確認を待ってください。

⑤ 少量で試運転する

brief.md と research-instructions.md を読み、まず2件だけ処理してください。
Web閲覧ができる場合だけ公開情報を確認し、実際に見たURLと確認日時を残してください。見られない情報は「未確認」とし、URL・数字・判定を作らないでください。ログイン・CAPTCHA・アクセス制限は回避しません。
結果は outputs に日付とバッチ番号つきのCSVで保存し、件数と未確認の項目を報告してください。

⑥ 小分けで進める

試運転と同じ手順で、次の【5】件を処理してください。既存の候補一覧・保留一覧と重複しないように確認し、原本は書き換えないでください。
終わったら 有効／保留／除外／重複候補 の件数と、残りの必要件数を報告して止まってください。

⑦ 納品前に検品する

検品担当として、brief.md の条件と outputs のデータを照合してください。
確認：必須列の空欄／重複／数値の範囲／根拠URLの有無／判定と理由の矛盾。
「機械的に確認できたこと」と「人がページを開いて確かめるべきこと」を分けて、行ID・問題・修正案の一覧を outputs に保存してください。件数が足りなければ、足りているように見せないでください。

⑧ 納品報告を書く

次の内容で、発注者への納品メッセージを短く丁寧に書いてください。
納品物の場所／有効件数／保留・除外の件数と主な理由／確認した方法／未確認で残っていること／修正対応の可否
私が伝えていない作業や品質を付け足さないでください。

⑨ 途中で相談する（遅れそう・条件が合わない）

発注者に途中経過を相談するメッセージを書いてください。
現在の件数／止まっている理由（事実だけ）／こちらから出せる選択肢を2つ（例：期限の延長、条件の確認）／いつまでに返事が欲しいか
言い訳や謝りすぎは不要です。相手が判断しやすい形にしてください。 → 黙って遅れるより、早めの相談のほうが信頼につながります

よくあるつまずきと、返す一言

😵AIが存在しないURLや数字を書いた
「この行の根拠URLを開いて確認できた内容だけにしてください。確認できなければ未確認にしてください」
📈件数を合わせるために条件をゆるめた
「条件は依頼書のまま戻してください。足りない件数はそのまま報告してください」
💾「保存しました」なのにファイルがない
「実際に作成されたファイルのパスを確認して教えてください」
🔁一度にたくさん処理しようとする
「指定した件数だけ処理して止まってください」
