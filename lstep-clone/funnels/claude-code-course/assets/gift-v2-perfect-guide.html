1　始める前に用意するものぜんぶ無料でそろいます（執筆時点）

  • パソコン（Windows・Mac どちらでも）。講座の画面はスマホでも見られますが、進めるのはパソコンが楽です
  • ブラウザ（インターネットを見るアプリ）。Google Chrome・Safari・Edge など、ふだん使っているもので大丈夫です
  • Googleアカウント（Gmailのアドレス）。講座へのログインに使います。講座はGoogleでしかログインできません
  • AIのアカウント（Claude か ChatGPT のどちらか1つ）。講座の画面には「無料のアカウントでも使えます」とあります
  • 1回30分ほどの時間。一度に全部やらなくても、途中で閉じれば次は続きから始まります
おすすめ：講座の画面とAIの画面を、ブラウザの別々のタブで開いておくと、行ったり来たりが楽です（タブの開き方は2章）。

「Claude Code・Codex」は無くても大丈夫

講座には「この画面で話す」と「Claude Code・Codexで話す」の2つの進め方があります。初めての方は「この画面で話す」で全部進められます。

Claude Code・Codex は、パソコンの中で動くAIのアプリです。使う場合は次が要ります（執筆時点）。

  • Claude Code：Claude の有料プラン／Codex：ChatGPT の有料プラン
  • Node.js（18以上）というソフト。無ければ、Claude Code・Codex に「Node.jsを入れて」と頼めば入れてくれます

料金やプラン名は変わることがあります。契約する前に、各サービスの公式ページで確かめてください。講座の会費と、AIの利用料は別です。

2　パソコンの基本操作この表のキーだけ覚えれば、講座は進められます

やりたいことWindowsMacメモ
コピーCtrl＋C⌘＋C先に文字をなぞって選ぶ
貼り付けCtrl＋V⌘＋V入れたい欄を先にクリック
全部を選ぶCtrl＋A⌘＋A長いAIの答えを丸ごと写す時に
1つ前に戻すCtrl＋Z⌘＋Z消しすぎた時の味方

Windows の Ctrl は、Mac では ⌘（command）に置きかわると覚えるとラクです。

コピー＆貼り付けを、1回練習しておきましょう

  1. 写したい文字の始まりで、マウスのボタンを押したままにする
  2. そのまま文字の終わりまでなぞって、色が変わったら指を離す
  3. Ctrl＋C（Mac は ⌘＋C）を押す。見た目は何も変わりませんが、これで写せています
  4. 貼りたい欄を1回クリックして、点滅する縦線（カーソル）を出す
  5. Ctrl＋V（Mac は ⌘＋V）を押す
講座では、なぞる必要はほとんどありません。依頼文や応募文の横にある コピー ボタンを押すだけで写せます。

スクショの撮り方と送り方

  1. 困っている画面を出したまま、上の表の「スクショ」のキーを押す
  2. 十字の印が出たら、写したい範囲をなぞる
  3. Windows：右下に出る通知を押すと保存できます／Mac：デスクトップに画像ができます
  4. LINEのトーク画面の「＋」や画像のマークから、その画像を選んで送る
送る前に：パスワード・メールアドレス・住所・電話番号が写っていないか確かめてください。写っていたら、その部分を外して撮り直しましょう。

3　AIとのつき合い方AIは「とても物知りな新人さん」だと思ってください

AIにできること・苦手なこと

得意なこと
文章の下書き、言い換え、要点のまとめ、手順の説明、たくさんの案を出すこと
苦手なこと
まちがいを自信満々に言うことがある／あなたのことは教えないと分からない／最新の情報を知らないことがある

うまく頼む3つのコツ

  1. 目的を言う：「クラウドワークスの応募文を作りたい」のように、何のためかを先に書く
  2. 材料を渡す：募集の文や自分の経験など、AIが知らないことは貼って渡す
  3. 形を決める：「300字で」「箇条書きで」「3つ案を出して」と、欲しい形を書く

講座の依頼文には、この3つが最初から入っています。あなたはコピーして送り、質問に答えるだけです。

AIの答えは、必ず自分の目で確かめる

  • 自分の経験と違うこと（やっていないこと・持っていない資格）が書かれていたら、消すか直してもらう
  • 数字（金額・日付・文字数）は、もとの情報と見比べる
  • 直してほしい時は「〇〇の部分を△△に直して」と、場所と直し方を伝える

AIの答えが変になった時の3つの言葉

こんな時こう送る
話が長くて分からない「もっと短く、中学生にも分かる言葉で」
質問の意味が分からない「例を3つ出して」
話がずれてきた「最初の目的に戻って、次にやることを1つだけ教えて」
AIに絶対に送らないもの：パスワード、認証コード（SMSなどで届く数字）、クレジットカードや口座の番号、マイナンバー。講座でこれらを聞くことはありません。

4　講座の始め方ログインから、1回目の会話を保存するまで

ログインする（はじめの1回だけ）

  1. LINEの「冒険を始める」を押して、講座の画面を開く
  2. 画面の左下にある「押してGoogleでログイン」を押す
  3. Googleのアカウントを選ぶ画面が出たら、使いたいアドレスを押す
  4. 講座の画面に戻り、左下が「Googleでログイン中」になっていれば完了です

新しく会員登録をする手順はありません。ログインした時点で、あなた専用の記録が始まります。ログインは30日間続きます。

「どこで話しますか？」→「この画面で話す」を選ぶ

  1. この画面で話す を押す（次からは、選んだ方が自動で選ばれます）
  2. Claudeを開く か ChatGPTを開く の、ふだん使う方を押す。AIが新しいタブで開きます
  3. 講座の画面に戻り、依頼文の コピー を押す
  4. AIのタブで、入力欄に貼り付けて送る
  5. AIからの質問に答えていく。分からない質問は「分からない」と答えて大丈夫です
  6. AIが最後に結果をまとめたら、その答えを丸ごとコピーする
  7. 講座の画面に戻り、「AIの最後の答えを貼る」欄に貼り付ける
  8. 結果として保存する を押す。これでQUESTの結果が画面に残ります
つまずきやすい所：6で「最後の答え」だけを写すのがポイントです。途中の質問まで混ぜると「結果の形が読み取れませんでした」と出ることがあります（7章）。

Claude Code・Codex を使う人は

  1. Claude Code・Codexで話す を押し、出てきた依頼文を コピー する
  2. Claude Code か Codex に貼って送る。必要な道具はAIが自動で入れます
  3. 「Claude Code・Codex とつなぐ」画面が開いたら、Googleでログインする
  4. 画面に出る確認の4文字が、AIの画面の4文字と同じか見比べる
  5. 同じなら このアカウントでつなぐ を押す。「つなぎました」と出れば完了です

つなぐ画面は10分以内に1回だけ使えます。時間が切れたら、もう一度AIに「スキルクエストの続き」と頼めば出し直せます。話した内容は、数秒〜10秒ほどで講座の画面に映ります。

5　QUEST 1〜5 の進め方1つずつクリアすれば、最初の応募までたどり着きます

QUEST 1スキル診断｜あなたの売り物を見つける
やること
これまでの仕事や経験、得意なこと、やりたくないことを、質問に答えて話す
手に入るもの
「売り物の正本」：スキルのレベル（Lv1〜5）、メインの売り物1つとサブ最大2つ、値段の目安、受けない仕事、提案文のひな形
つまずき
「自分には売り物なんて無い」と思っても大丈夫。家事・接客・趣味の経験も材料になります。思い出せる範囲で答えましょう
QUEST 2プロフィール作成｜選ばれる自己紹介を作る
やること
6つの段に分かれた質問に答える（目安30分）
手に入るもの
長さ違いの自己紹介文（160〜3000字）と、サイトごとに貼るだけの入力内容
自分でやる
クラウドワークスなど各サイトへの会員登録と、プロフィールの保存ボタン。登録のパスワードは自分で決めて、自分で控えます（AIには送らない）
つまずき
実績が少なくても、事実だけを書けば大丈夫。盛った内容は後で自分が困ります
QUEST 3案件探し｜条件に合う仕事を集める
やること
最低の単価、1か月に使える時間、在宅だけか、などの条件を答える
クリアの合図
気になる案件で 応募する候補に入れる → この◯件に応募する
知っておくこと
自動で集めるのはクラウドワークス・ランサーズ・ココナラ・Workship。ほかのサイトは、講座のボタンで検索画面を開き、自分で見て足します（Wantedly は手で書き写します）
つまずき
「スプシに反映」でGoogleの確認画面が出たら、「ファイル」の許可にチェックを入れてから進みます
QUEST 4応募文づくり｜案件ごとに応募文を作って送る
やること
案件ごとに ① 応募文をコピー → ② 募集ページへ → サイトで貼って送る → ③ 応募する
クリアの合図
全部送れたら 応募は全部送り終わった
自分でやる
応募の送信ボタンを押すのは、必ず自分です。送る前に、募集の条件と応募文を一度読み比べましょう
QUEST 5やり取り管理｜返信から面談までを整える
やること
相手から届いたメッセージを「相手から届いたメッセージを貼る」に貼ると、返信の下書きが出ます。送ったら 送った を押す
面談
Googleカレンダーとつなぐと、空いている時間を一緒に探せます。予定の登録ボタンは自分で押します
知っておくこと
このQUESTに終わりはありません。スカウト・問い合わせが来た・今日の新着を見た で、毎日の動きを記録していきます

6　安全に進めるための約束あなたの身を守るためのルールです

AI・講座・LINE、どこにも送らないもの

  • パスワード、認証コード
  • クレジットカード・銀行口座の番号、マイナンバー

講座が文面を取り込む時は、メールアドレスや電話番号を「（連絡先）」に置きかえて扱います。

押すのは、いつも自分

応募の送信・会員登録・ログイン・支払い・申込は、AIが代わりに押すことはありません。最後のボタンは、内容を確かめてから自分で押します。

怪しい案件の見分け方

こんな案件は見送るのが安全です
LINEなど、サイトの外へ連絡を誘うトラブルが起きてもサイトが守ってくれません
始める前にお金がかかる（教材費・登録料）仕事を受ける側がお金を払うことは、ふつうありません
報酬が相場より極端に高い・低い高すぎる話は疑う。安すぎる仕事は続きません
仕事の中身があいまい「誰でも簡単」「すぐ稼げる」だけの募集は避ける

手数料のこと

案件サイトは、報酬から手数料を引きます。講座内の記載では、クラウドワークス・ココナラは約22%、ランサーズは約16.5%です（執筆時点・変わることがあるので各サイトで確かめてください）。値段を決める時は、手取りで考えましょう。

大事なこと：この講座は、案件を取るための手順と道具をお渡しするものです。収入を約束するものではありません。続けるほど、応募の数と質は上がっていきます。

7　困ったとき集画面に出た言葉で探してください

「保存するにはログインが必要です」と出た
左下の「押してGoogleでログイン」からログインしてから、もう一度保存してください。
「結果の形が読み取れませんでした」と出た
AIの「最後の答え」だけを、始めから終わりまで全部コピーし直して貼ってください。足りない時は、AIに「最後の結果を、もう一度まとめて出して」と頼みます。
「このアカウントでは、この画面からAIは動きません」と出た
Claudeを開く か ChatGPTを開く を押して、自分のAIで話す進め方を使ってください（4章）。
Googleの確認画面のあと、許可が足りないと言われた
もう一度ボタンを押し、確認画面で「ファイル」（カレンダーの時は「カレンダー」）の横にチェックを入れてから進んでください。
「Google の回数の上限に当たりました」と出た
壊れたわけではありません。1分ほど待ってから、もう一度押してください。
ボタンを押しても画面が変わらない・固まった
ページを読み込み直してください（Windows F5／Mac ⌘＋R）。進めた内容は、保存した所まで残っています。
途中でやめてしまった。最初からやり直し？
いいえ。講座を開くと「つづきからはじめる」が出ます。終わったQUESTも 修正する から直せます。
Claude Code・Codex の「つなぐ」画面が開かない・時間切れになった
つなぐ画面は10分以内に1回だけ使えます。AIに「スキルクエストの続き」と送ると、もう一度出してくれます。
AIの質問が難しくて答えられない
「分からない」「例を3つ出して」と送れば、答えやすい形にしてくれます。
スマホでもできる？
画面を見ることはできます。文章のコピーや貼り付けが多いので、進めるのはパソコンがおすすめです。

8　講師への聞き方ひとりで30分悩んだら、聞いてください

  1. 公式LINEのメニューから「講師に相談」を押す
  2. 届いたフォームに、下のひな形をコピーして書き込む
  3. 困っている画面のスクショがあれば、トークにも送る（パスワードなどが写っていないか確かめてから）
【いまのQUEST】QUEST ○（例：QUEST 2 プロフィール作成） 【やりたいこと】（例：クラウドワークスにプロフィールを保存したい） 【やったこと】（例：コピーを押して、AIに貼って送った） 【起きたこと】（例：「結果の形が読み取れませんでした」と出た） 【使っているもの】パソコン（Windows／Mac）・AI（Claude／ChatGPT）

この5つがそろっていると、1回のやり取りで解決しやすくなります。うまく書けなくても大丈夫です。分かる所だけ書いて送ってください。

さあ、冒険へ。LINEのメニューの「冒険を始める」を押して、QUEST 1「スキル診断」から始めましょう。
