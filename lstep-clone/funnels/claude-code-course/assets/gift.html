AIと学ぶ方法（4ステップ）

  1. 普段のAIチャットを開く … ChatGPT・Gemini・Claude など、いつものもので大丈夫。教材と別のタブで開きます。
  2. 「教材とプロンプトをコピー」して送る … 章ごとのボタンでコピーし、AIチャットに貼って送信します。
  3. 一つ案内されたら、やって返事をする … 分からないまま進めなくてOK。画面が違えば、秘密情報を隠したスクショを送ります。
  4. できた項目は、自分でチェックする … AIが教材に自動でチェックを付けることはありません。実物を見て、できていたら自分で付けます。

困ったときの“合言葉”

「一操作だけ案内して、私の返事を待ってください」AIが一度にたくさん指示してきたとき
「ここまでできました。この章のできたことチェックのうち、どの項目にチェックできますか？」どこまで進んだか分からなくなったとき（できた内容も一緒に伝える）
「まだできていません」AIは「できた」と言ったのに、実際のファイルや画面ができていないとき

World1 の地図（全10章）

0はじまりの書庫 … 案内役のAIとの進め方を知る
1可能性の展望台 … AIに頼みたい身近なことを一つ決める
2旅支度の広場 … パソコンの種類と始める章を確認する
3アカウントの門 … 自分のアカウントでログインする
4選択の広間 … 使えるプランと料金を確認する
5道具の工房 … アプリを入れて Code / Codex の入口を開く
6練習の作業台 … 空の練習フォルダを用意し、許可の設定を確かめる
7対話の灯台 … 日本語で話しかけて返事を確かめる
8小さな創作室 … 「今日やること.txt」を作って実物を開く
9工夫のアトリエ … 「10分を15分に」と自分の言葉で直す
10再出発の扉 … アプリを開き直し、同じ場所から再開する

途中で休憩して大丈夫です。進捗はブラウザに保存され、同じブラウザで「続きから学ぶ」を押せば再開できます。

安全に進めるための約束

  • パスワード・認証コード・カード番号・APIキーは、AIに送らない（入力は自分で公式画面に）
  • 契約・購入・削除・インストールは、内容を読んで自分で判断する
  • AIの「できました」は、実際のファイルや画面で確かめてからチェックする
  • アクセスの許可を聞かれたら、対象が練習フォルダで今回の作業に必要か確かめる

講師に相談するときのテンプレート

章：（例：道具の工房）
できたところ：（例：ダウンロードまで）
表示：（エラー文や画面。秘密情報は隠す）
試したこと：（例：アプリを開き直した）
確認したいこと：（例：この警告は進めて大丈夫？）

公式LINEで「質問」と送ると、講師への質問フォームが届きます。
