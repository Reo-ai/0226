クラウドワークス用プロフィール・提案文の型

AIと一緒に学ぶ講座「スキルクエスト」　作成者 茅森ショウ

この冊子の使い方

  1. まず「3つの原則」を読む（1分）。
  2. 自分に近い型を1つ選び、【　】を自分の事実で埋める。
  3. 営業武器の第4章（プロフィールの下書き）で、AIに一問ずつ聞いてもらいながら仕上げる。
  4. 最後に「公開前チェック」で確かめてから保存する。
テンプレは「骨組み」です。名前だけ差し替えて使うと、経験や得意なことまで他人のものになります。書いてよいのは、自分が実際にやったこと・できることだけ。実績がない項目は省くか「練習用サンプル」と明記します。

読まれるプロフィールの3つの原則

① 何を頼めるか

「何でもやります」より「出典付きの企業リストを作れます」。相手は自分の仕事を任せられるかを探しています。

② どう確かめるか

未経験の不安は「確認の手順」で埋めます。少量サンプル→認識合わせ→本作業→重複・欠損チェック→納品。

③ いつ連絡がつくか

稼働時間と返信の目安を正直に。守れない「即レス・24時間対応」は書きません。

ひとことアピール 10例

プロフィール一覧で最初に目に入る一文です。事実に合うものを選んで直しましょう。

1出典と確認日を残す、検品付きのリスト作成をお手伝いします
2企業リスト・Webリサーチを、重複チェックまでして納品します
3AIで下調べを速くし、最後は人の目で確認して仕上げます
4まず数件のサンプルで認識をそろえてから作業を進めます
5スプレッドシートの整理・表記ゆれの統一が得意です
6【平日夜／土日】に稼働。返信は【12時間以内】を目安にしています
7事務職【　】年の経験を活かし、正確なデータ入力を心がけています
8条件に合わない候補は「保留」として理由付きでお渡しします
9リサーチ結果は、根拠のURL付きで確認しやすい形にまとめます
10小さな案件から丁寧に。分からない点は作業前に確認します

自己PR テンプレ（3タイプ）

A. 完全未経験・これから実績を作る人

はじめまして、【公開名】と申します。プロフィールをご覧いただきありがとうございます。

【対応できるお仕事】
・企業リスト／営業リストの作成
・Webリサーチ（公開情報の収集と整理）
・スプレッドシートへのデータ入力・表記の統一

【進め方】
最初に数件のサンプルをお送りして、項目や判断基準に認識のずれがないか確認してから本作業に入ります。納品前には重複・空欄・リンク切れを確認し、条件を確認できなかったものは理由を添えて分けてお渡しします。

【実績について】
クラウドワークスでの実績はこれからですが、練習として【架空の依頼で20件のリストを作り、出典と確認日を付けて検品】しました（練習用サンプルとしてお見せできます）。

【使える道具】Googleスプレッドシート／Excel／【Claude Code・Codex などのAI】（下調べと整理に使い、最終確認は自分で行います）

【稼働時間と連絡】週【　】時間ほど、主に【平日夜・土日】に作業します。メッセージは【12時間以内】を目安にお返事します。

まずはお気軽に、クラウドワークスのメッセージでご相談ください。

B. 事務・接客などの社会人経験がある人

はじめまして、【公開名】です。【業種・職種】として【　】年、【データ入力／書類作成／顧客対応】などを担当してきました。

その経験から、【正確さ／期限を守ること／相手の意図を確認すること】を大切にしています。

【対応できるお仕事】リスト作成／Webリサーチ／データ入力／スプレッドシートの整理
【前職で担当していたこと】【例：月【　】件の受注データの入力と照合】
【進め方】少量サンプルで確認 → 本作業 → 重複・欠損の確認 → 指定形式で納品
【稼働】週【　】時間／返信目安【　】時間以内

※前職の会社名・顧客名など、公開できない情報は記載していません。

C. AIを使った効率化を強みにしたい人

はじめまして、【公開名】です。AI（【Claude Code／Codex】）を使った調べもの・データ整理を学び、リスト作成とリサーチのお仕事をお受けしています。

AIで候補集めや表の整形を速く進め、根拠のURLと条件は自分の目で一件ずつ確認してから納品します。AIが確認できなかった情報は推測で埋めず、「未確認」と分けてお伝えします。

※ご依頼内容にAI利用の可否がある場合は、その条件に従います。機密情報をAIに入力することはありません。

【稼働】週【　】時間／返信目安【　】時間以内

提案文テンプレ（リスト作成・リサーチ案件）

【発注者名】様

はじめまして、【公開名】と申します。【案件名】の募集を拝見し、ご提案させていただきます。

【ご依頼内容の理解】
【対象】について、【項目A・項目B・項目C】を調べ、【件数】件を【納品形式】でお渡しする、という理解で合っておりますでしょうか。

【進め方】
1. まず【3〜5】件をサンプルとしてお送りし、項目や判断基準をご確認いただきます
2. 認識をそろえたうえで残りを作業します
3. 納品前に重複・空欄・リンクを確認し、条件を満たさないものは理由付きで別シートに分けます

【関連する経験】【自分の事実。なければ練習用サンプルの説明】

【ご質問への回答】
Q1【募集文の質問】→【回答】

【納期・稼働】【　】日で納品可能です。作業時間は【平日夜・土日】、ご連絡には【　】時間以内にお返事します。

ご検討のほど、よろしくお願いいたします。
全案件で同じ文面を送らない。「ご依頼内容の理解」と「ご質問への回答」は、必ずその案件の募集文から書きます。ここが一番読まれる部分です。

AIに仕上げてもらうときの一言

このテンプレの【　】を、私の事実だけで埋めるのを手伝ってください。質問は一度に1つずつ。私が答えていないことは推測で書かず「未確認」としてください。 → 営業武器の第4章のプロンプトと一緒に使うと、さらに精度が上がります

公開前チェック

  • □ 書いてあることは、全部自分の事実か（年数・資格・実績を盛っていないか）
  • □ 練習用サンプルと実務実績を区別しているか
  • □ 【　】が残っていないか
  • □ 稼働時間・返信目安は守れる内容か
  • □ 住所・電話番号・前職の会社名や顧客名など、公開しない情報が入っていないか
  • □ ひとことアピール・自己PR・スキル欄・希望単価が矛盾していないか
  • □ 保存後、公開プロフィールを開いて表示を確かめたか
