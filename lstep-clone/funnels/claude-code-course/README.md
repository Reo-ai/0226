# スキルクエスト（Claude Code / Codex 講座）販売導線（公式LINE）

講座ページ: https://sho-claude-code-course.pages.dev/ （作成者 茅森ショウ）

配信文面とリッチメニューは、講座ページ（改良版 https://skillquest-v2.pages.dev/ ）の世界観に合わせ、講座内の案内役「冒険の書の守護者」がナレーターとして冒険者（友だち）に語りかける形にしています。World 1 マップ（相棒の村 → 営業の工房 → 調査の森 → 依頼の街 → ボス）・アイテム・称号の言葉を使いつつ、料金・必要なもの・合格条件は現実の言葉で明記します。

| 素材 | 場所 |
|---|---|
| 登録特典PDF「スキルクエストの歩き方」 | `public/gift/skillquest-start-guide.pdf`（スキルステップから `/gift/skillquest-start-guide.pdf` で配信。元HTMLは `assets/gift.html`） |
| リッチメニュー画像（通常・4分割・リアルRPG風） | `assets/richmenu-normal.jpg`（2500×1686。元は `richmenu-normal.html` ＋ `rpg-menu.css`、絵は `richmenu-art/`） |
| リッチメニュー画像（購入者・4分割・リアルRPG風） | `assets/richmenu-buyer.jpg`（2500×1686。元は `richmenu-buyer.html`） |

> 期限内特典3つは、講座ページにある講師サポートから組んだ**仮案**です。講師が提供できるか確認してから公開してください。

すべての設定は [`funnel.mjs`](./funnel.mjs) にまとまっています。冒頭の `CONFIG` を埋めて、1コマンドで管理ツールに投入します。

```bash

node scripts/seed-funnel.mjs funnels/claude-code-course/funnel.mjs --dry-run
# 2. 投入（アプリを一度起動してDBができている状態で。本番は DATABASE_URL を本番DBに向ける）
node scripts/seed-funnel.mjs funnels/claude-code-course/funnel.mjs
# 文面を直したあとシナリオを作り直す（進行中の配信位置はリセットされる）
node scripts/seed-funnel.mjs funnels/claude-code-course/funnel.mjs --replace
```

## 1. 設計の全体像

```
 SNS / 講座ページ ──(流入経路URL: 媒体タグ)──▶ 友だち追加
                                                 │ 即時(無料): あいさつ＋特典＋「1/2/3で返信」
                                                 ▼
        ┌──────── 【本線】7日間教育 → 講座案内 → 締切（友だち追加で開始 / 購入済みで停止）────────┐
        │ Day1 20:00 未来の話      Day2 20:00 つまずく理由   Day3 20:00 作れるもの＋実例        │
        │ Day4 20:00 3つの誤解     Day5 12:00 予告           Day6 20:00 講座案内（締切3日）     │
        │ Day7 20:00 FAQ           Day8 12:00 特典・残り1日  Day9 8:00/21:00/23:00 締切3連      │
        │ Day10 20:00 締切後フォロー（関係維持）                                                │
        └──────────────────────────────────────────────────────────────────────────────────────┘
          │ {{link:lp}} クリック → LP閲覧タグ → 【追客】翌日12:30「自分にできる？」への回答
          │ {{link:checkout}} クリック → 決済ページ閲覧タグ → 【追客】1時間後 決済の不安解消
          ▼
   「購入しました」と送る → 受講登録フォーム → 購入済みタグ
          → 本線・追客を自動停止 ／ 【購入者】オンボーディング30日 開始
```

### この導線の「勝ち筋」

| 設計の要点 | なぜ効くか |
|---|---|
| **初日に「数字で返信」させる** | 返信のハードルが最も低い質問で会話を始めると、その後の開封・反応率が上がる。返信は応答メッセージなので**通数0** |
| **World1 を“宿題”にする** | 講座の一部を先に体験 → 「できた」と送らせる。小さな成功体験＋コミットメントが購入の最大の後押し |
| **教育4日 → 予告 → 案内** | いきなり売らない。未来(Day1) → 問題(Day2) → 解決策と証拠(Day3) → 反論処理(Day4) → 予告(Day5)で期待を作ってから案内 |
| **締切は「登録日基準」** | 全員に同じ体験（エバーグリーン）。いつ登録しても7日目に案内、9日目に締切 |
| **締切3連（朝・残り3時間・残り1時間）** | 売上の大半は最終日に集中する。最終日に3回接触するのが定石 |
| **行動で追いかける** | LPを見た人・決済ページで止まった人だけに、その不安に合わせたフォロー |
| **購入者には二度と売らない** | 停止タグで販売系を自動停止。購入後はオンボーディングで挫折防止 → 感想・紹介依頼へ |
| **配信は20時中心・時刻固定** | 「開始日から◯日後の20:00」で届くので深夜に通知が鳴らない |

### ペルソナ

- 30〜40代の会社員・個人事業主。ChatGPT は触ったが「コピペ止まり」
- プログラミング経験はない／少ない。「AIで仕事を楽にしたい」「副業や自分のサービスに活かしたい」
- 不安: 難しそう・時間がない・自分にできるか

## 2. タグ設計

| 種類 | タグ | 付くタイミング |
|---|---|---|
| 流入 | 流入_Instagram / TikTok / X / YouTube / 講座ページ | 流入経路URLから友だち追加 |
| レベル | レベル_完全初心者 / ChatGPTは使える / エンジニア | 初日の質問に「1/2/3」で返信 |
| 行動 | 特典受取・World1体験・アンケート回答・質問あり | リンククリック／「できた」返信／フォーム回答 |
| 温度 | LP閲覧 → 決済ページ閲覧 | 計測リンクのクリック |
| 状態 | 購入済み | 受講登録フォーム回答（または管理画面で手動付与） |

**購入者の判定**: 決済サービスとの自動連携はないため、①サンクスページ／決済完了メールに「LINEで『購入しました』と送ってください」と書く、②届いたら受講登録フォームで「購入済み」タグが付く、の流れにしています。決済一覧と照合して、漏れは管理画面で手動付与してください。

## 3. キーワード応答

| 送られた言葉 | 返すもの | タグ |
|---|---|---|
| `1` / `2` / `3`（完全一致） | レベル別のメッセージ＋World1 | レベル_◯◯ |
| 「できた」を含む | 称賛＋明日の予告 | World1体験 |
| 「特典」を含む | 特典リンク | （クリックで特典受取） |
| `アンケート完了` | 追加特典 | |
| 「購入しました」「購入完了」「申し込みました」を含む | 受講登録フォーム | （回答で購入済み） |
| 「アンケート」を含む | アンケートフォーム | |
| 「質問」を含む | 質問フォーム | （回答で質問あり） |
| 「講座」を含む | 講座ページ | |
| `スタート` | World1 への誘導（購入者向け） | |

部分一致は上から順に判定するため、「講座を購入しました」は購入、「講座について質問」は質問として扱われます（検証済み）。

## 4. リッチメニュー（管理画面「リッチメニュー」→「自分で作った画像を使う」で登録）

画像は 2500×1686（4分割）。2026-10-05 に6分割＋タブ（できた／習慣メニュー）から4分割に整理した（「最初のクエスト」と「冒険の書」が同じ講座ページを開いていたため1つにまとめ、アンケートは「アンケート」と送れば出る）。習慣トラッカーはメニューから外したが、「習慣」「できた」と送れば今まで通り使える。

**通常メニュー（デフォルト）**

| 位置 | 表示 | 動作 |
|---|---|---|
| 左上 | 冒険の地図（登録特典） | テキスト送信「特典」 |
| 右上 | 冒険の書（講座を見る・無料で始める） | テキスト送信「講座」 |
| 左下 | 講師に相談 | フォーム案内（講師への質問フォーム） |
| 右下 | 冒険者登録（購入した方） | テキスト送信「購入しました」 |

**購入者メニュー（タグ「購入済み」で自動切替）**: 「冒険を始める（スタート）」「World マップ（講座ページ）」「講師に相談（質問フォーム）」「旅の記録（感想）」

> メニューのボタンはすべて「相手からの反応」になるので、押すたびに届く情報は**通数0**です。

## 5. 通数とプラン

本線は1人あたりプッシュ13通（Day1〜Day10）、追客で最大2通です。

- LINE公式の無料プラン（月200通）では約15人分しか送れません。**友だち数×15通**を目安に有料プランを選んでください
- 上限に達しても止まらず、ツールが自動で「相手の反応時に無料で届ける」に切り替えます（その分、到達は遅れます）
- 管理画面「設定」の「プッシュ上限」を契約プランの通数に合わせて変更してください

## 7. KPIと改善の回し方

| 指標 | 見る場所 | 目安 | 低い時に直すところ |
|---|---|---|---|
| 初日返信率（1/2/3） | タグ別人数 ÷ 友だち数 | 40%以上 | あいさつの質問文・選択肢 |
| World1 体験率 | World1体験タグ | 25%以上 | Day1の宿題の出し方・リンク位置 |
| ブロック率（配信24h） | 分析 | 1通あたり1%以下 | その日の文面の長さ・売り込み感 |
| 講座ページ到達率 | LP閲覧タグ ÷ Day6到達者 | 30%以上 | Day5の予告・Day6の冒頭 |
| 決済ページ到達率 | 決済ページ閲覧 ÷ LP閲覧 | 30%以上 | 講座ページ側（価格の見せ方・特典） |
| 成約率 | 購入済み ÷ 友だち数 | 3〜5% | 締切3連・FAQ・特典 |
| シナリオ離脱 | 分析（シナリオ離脱率） | — | 離脱が多いステップの前の配信 |

改善は**1回に1か所だけ**変えて、2週間分の数値で比較します。
