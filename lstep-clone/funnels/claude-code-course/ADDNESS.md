# Addness 登録用ゴールツリー

この環境からは Addness に接続できなかったため、そのまま貼り付けられる形で出力しています。
（✅ = 今回完了 / ⬜ = 残り。残りはすべて人の手が必要な作業です）

## ゴール: 公式LINEで Claude Code 講座が自動で売れる導線を完成させる

- ✅ 導線の全体設計（ペルソナ・オファー・タグ・フロー）
  - ✅ ペルソナと「勝ち筋」の定義
  - ✅ タグ設計（流入・レベル・行動・温度・状態）
  - ✅ 全体フロー（友だち追加 → 教育 → 案内 → 締切 → 購入後）
- ✅ 配信ツールの機能追加
  - ✅ 停止タグ（購入済みになったら販売系シナリオを自動停止）
  - ✅ 時刻指定のステップ配信（◯日後の20:00 など）
- ✅ シナリオ・ステップ配信の文面
  - ✅ 【本線】ウェルカム → 7日間教育 → 講座案内 → 締切（13通）
  - ✅ 【追客】講座ページを見た人（1通）
  - ✅ 【追客】決済ページまで進んだ人（1通）
  - ✅ 【購入者】オンボーディング30日（6通）
- ✅ キーワード応答・フォーム・計測リンク・流入経路
  - ✅ キーワード応答 13件（1/2/3・できた・特典・購入しました・質問 など）
  - ✅ フォーム 3件（30秒アンケート・質問・受講登録）
  - ✅ 計測リンク 4件（講座ページ・World1・決済・特典）
  - ✅ 流入経路 5件（Instagram・TikTok・X・YouTube・講座ページ）
  - ✅ リッチメニュー仕様（通常／購入者）
- ✅ 一括投入スクリプトと動作検証（友だち追加〜購入後まで疑似ユーザーで確認）
- ⬜ 公開準備（人の作業）
  - ⬜ 価格・期間限定価格を決めて CONFIG に入れる
  - ⬜ 期限内特典を3つ決めて CONFIG に入れる
  - ⬜ 受講生の声（または講師のビフォーアフター）を2つ用意する
  - ⬜ 決済ページを用意し URL を CONFIG に入れる
  - ⬜ 決済完了ページに「LINEで『購入しました』と送ってください」を記載
  - ⬜ 登録特典PDFを作成し URL を CONFIG に入れる
  - ⬜ リッチメニュー画像を2枚作成（通常・購入者）して設定
- ⬜ 本番投入と実機テスト
  - ⬜ 本番DBへ投入（seed-funnel.mjs）
  - ⬜ LINE公式の契約プランを決め、プッシュ上限を設定
  - ⬜ 自分のLINEで全キーワード・フォーム・購入の流れを確認
- ⬜ 集客の入口を設置
  - ⬜ 各SNSプロフィールに流入経路URLを設置
  - ⬜ 講座ページに友だち追加バナー（流入経路 course）を設置
- ⬜ 運用・改善（公開2週間後から）
  - ⬜ KPI（初日返信率・World1体験率・ブロック率・成約率）を確認
  - ⬜ 一番低い指標の配信を1か所だけ改善 → 2週間比較
