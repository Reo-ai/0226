# キャラクター バイブル
## 作曲初心者向けショート動画シリーズ

## CHARACTER 01 ── 作曲先生

### ビジュアル仕様

| 要素 | 詳細 |
|------|------|
| 性別・年齢 | 女性・30代前半 |
| 髪型 | ゆるふわショートボブ、明るいブラウン |
| 顔 | 丸みのある輪郭、大きな目、細縁メガネ（丸型）|
| 服装 | 明るいグリーンのカーディガン、白のインナー、スカーフ（柄物）|
| 小物 | 指揮棒 or 鉛筆、楽譜ノート（"Music" と書かれた表紙）|
| 体型 | 中肉・小柄・明るい印象 |
| 肌色 | 明るい肌 |
| 目の色 | 茶色 |

### 性格・役割

- **役割：** 優しく丁寧に解説する先生
- **口調：** 「〜ですよ」「〜してみましょう！」「大丈夫です♪」
- **感情表現：** にこやか、うなずき、驚き（大げさにならない程度）
- **NG：** 上から目線、難しい専門用語のまま放置

### 感情バリエーション

| 感情 | 使用場面 |
|------|---------|
| 笑顔・解説中 | 通常のポイント説明 |
| うなずき・共感 | 生徒の悩みを聞いているとき |
| 驚き・発見 | 「実はこんな簡単な方法が！」 |
| 指差し・強調 | 重要ポイントの提示 |
| 励まし・応援 | まとめ・CTA |

## CHARACTER 02 ── 作曲ネコ

### ビジュアル仕様

| 要素 | 詳細 |
|------|------|
| 種族 | 黒猫（擬人化）・二足歩行 |
| 体型 | ふくよか・ずんぐり・愛嬌あり |
| 耳 | ピンと立った猫耳 |
| 目 | やや細め、眠そうな緑色の目 |
| ヘッドフォン | 大きめ、ライトブルー（耳にかかっている）|
| 服装 | ネイビーブルーのパーカー（フード付き）、胸に星マーク⭐ |
| 小物 | 鉛筆（口や手に持つ）、楽譜ノート |
| しっぽ | 長くてふさふさ、感情を表現する |

### 性格・役割

- **役割：** 初心者目線で悩む・共感キャラ
- **口調：** 「〜ニャ」「うーん…」「むずかしいニャ」「あくびニャ…」
- **感情表現：** 大げさ・コミカル・オーバーリアクション
- **NG：** 知識をひけらかす、先生より詳しそうに見える

### 感情バリエーション

| 感情 | 使用場面 |
|------|---------|
| 困り顔・頭を抱える | Beforeの悩みを体現 |
| あくび・眠そう | 「難しくてもう無理ニャ…」 |
| 目を輝かせる | 「わかったニャ！！」 |
| ずっこける・転ぶ | コミカルな失敗シーン |
| ガッツポーズ | 「できたニャ！！」 |
| 首をかしげる | 「これってどういう意味ニャ？」 |

## キャラクター関係性

```
作曲先生 ──（優しく教える）──→ 作曲ネコ
作曲ネコ ──（素直に学ぶ）  ──→ 視聴者の共感

視聴者 = 作曲ネコ と同じ目線で見る
```

## Pixar風3Dスタイル指定

- **モデリング：** 丸みを帯びたフォルム、シャープなエッジなし
- **テクスチャ：** サブサーフェス・スキャッタリング（肌の透明感）
- **目：** 大きく輝く、ハイライト2点、アニメ的表現
- **照明：** ソフトな3点ライト（キー+フィル+リム）、暖色ベース
- **背景：** シンプルなスタジオ風 or DAW部屋（ぼかし）
- **参考作品：** Pixar「ソウル」「マイ・エレメント」のキャラスタイル
