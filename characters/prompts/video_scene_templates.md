## 標準30秒構成（キャラクター使用版）

```
[0〜3秒]  ── フックシーン
  キャラ : 作曲ネコ（困り顔）
  演出  : ネコが悩んでいる → テロップでテーマ提示
  セリフ : 「（テーマの悩み）ニャ…」

[3〜8秒]  ── Before再生
  キャラ : 作曲先生（うなずき・共感）
  演出  : DAW画面 + 先生の小窓（ワイプ）
  セリフ : 「こういう演奏、よく聞きますよね」

[8〜18秒] ── 解説パート
  キャラ : 作曲先生（指差し・解説）
  演出  : テロップ + 先生のアップ
  セリフ : 改善ポイントを1〜2文で説明

[18〜25秒] ── After再生
  キャラ : 作曲ネコ（目を輝かせる）
  演出  : DAW画面 + ネコのリアクション小窓
  セリフ : 「わかったニャ！！全然違うニャ！」

[25〜30秒] ── まとめ・CTA
  キャラ : 2人並び（先生：励まし、ネコ：ガッツポーズ）
  演出  : まとめテロップ + フォロー促し
  セリフ : 先生「保存して試してみてください♪」
```

## シーン別 映像仕様

### Scene A : フック（0〜3秒）
```
キャラ  : 作曲ネコ（単独）
表情   : 困り顔 / あくび / 頭を抱える（テーマによる）
カメラ  : バストアップ、正面
背景   : シンプルスタジオ（グラデーション）
テロップ: 大きなフォント、中央配置
アニメ  : キャラがポコッと現れる（バウンスイン）
```

### Scene B : Before DAW（3〜8秒）
```
メイン  : DAW画面録画（ピアノロール or 波形）
ワイプ  : 右下に先生（小窓・共感顔）
テロップ: 「❌ Before」ラベル + 問題点の一言
```

### Scene C : 解説（8〜18秒）
```
キャラ  : 作曲先生（バストアップ）
表情   : 指差し → うなずき → 強調
カメラ  : 正面 → やや寄り（ポイントで）
テロップ: ポイントを箇条書き（2〜3点まで）
アニメ  : テロップが順番に出てくる
```

### Scene D : After DAW（18〜25秒）
```
メイン  : DAW画面録画
ワイプ  : 右下にネコ（目を輝かせる / ガッツポーズ）
テロップ: 「✅ After」ラベル + 改善点の一言
SE    : キラキラ音 or ポジティブなジングル
```

### Scene E : まとめCTA（25〜30秒）
```
キャラ  : 2人並び（ワイド）
表情   : 先生＝励まし、ネコ＝ガッツポーズ
テロップ: まとめ1行 ＋「保存はここ👇」
アニメ  : ハートや星が舞う
ハッシュタグ: #作曲初心者 #DTM入門 #作曲のコツ
```

## テロップデザイン仕様

```
フォント  : Noto Sans JP Bold (日本語)
フックテキスト: 48〜56px、白、黒縁取り2px
解説テキスト : 32〜36px、白、黒縁取り1.5px
強調ワード : 黄色 (#FFD700) or ライム (#A8FF3E)
NG      : 読みにくい細字フォント、背景と同化する色
アニメ   : ポップイン（0.2秒）or スライドイン（左から）
```
